# etolegko-speed-test

Консольный скрипт измеряет скорость скачивания ресурса за 10 последовательных запросов GET. Каждый запрос открывает новое соединение.

## Запуск

Нужен Node.js 22 или новее. Устанавливать пакеты не требуется.

```sh
git clone https://github.com/MishaMgla/etolegko-speed-test.git
cd etolegko-speed-test
node measure-download.mjs 'https://example.com/'
```

Подставьте прямой HTTP(S)-адрес ресурса. Указывайте URL в кавычках, если в нём есть параметры. При перенаправлении укажите конечный адрес.

Скрипт выводит число запросов, среднее время запроса в миллисекундах, общий объём тел ответов в байтах и скорость в MiB/s. Один MiB равен 1 048 576 байтам. Скорость рассчитывается по общему объёму и сумме длительностей всех запросов. Отсчёт идёт от начала каждого запроса до полного чтения тела. Данные обрабатываются по мере поступления.

При ошибке скрипт останавливается, пишет причину в stderr и возвращает код `1`. Запрос прерывается после 60 секунд без прогресса. Таймер сбрасывается при получении заголовков и каждой порции тела.

## Тесты

```sh
node --test
```

Тесты запускают CLI как отдельный процесс и используют локальный HTTP-сервер.
