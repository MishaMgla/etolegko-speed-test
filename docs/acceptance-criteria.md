# Критерии приёмки

| Критерий | Как проверить |
| --- | --- |
| CLI принимает один абсолютный URL ресурса по HTTP или HTTPS. Успешный запуск завершается с кодом `0`. | Запустить команду из README с адресом тестового сервера. |
| CLI выполняет ровно 10 запросов GET к указанному URL. Каждый следующий запрос открывает новое соединение после полного чтения тела предыдущего ответа. | Тестовый сервер проверяет, что получил 10 запросов на 10 разных TCP-сокетах без пересечений, и отправляет последнюю часть каждого тела с задержкой. |
| CLI суммирует фактически прочитанные байты тел всех 10 ответов. HTTP-заголовки и служебные данные передачи в объём не входят. | Сервер отдаёт двоичные тела разного размера без `Content-Length`. Тест сверяет результат с точным объёмом `61440` байт. |
| Среднее время в миллисекундах равно сумме длительностей 10 запросов, делённой на 10. Длительность включает ожидание заголовков и чтение тела. | Тест проверяет, что среднее учитывает задержки заголовков и последней части тела, а суммарный замер укладывается во время работы CLI. |
| Скорость в MiB/s равна общему объёму в байтах, делённому на `1 048 576` и суммарное время запросов в секундах. | Тест пересчитывает скорость из напечатанного объёма и среднего времени с учётом округления. Для 10 пустых успешных ответов объём и скорость равны нулю. |
| Неправильные аргументы, ответ вне диапазона `2xx`, обрыв соединения или тайм-аут завершают запуск с кодом `1` и сообщением в stderr. При ошибке итоговые метрики отсутствуют. | Тесты проверяют аргументы, ответы `101`, `302` и `404`, обрыв тела и сообщение о тайм-ауте. |
| От начала запроса до заголовков и между порциями ответа допускается до 60 секунд без прогресса. Получение заголовков и каждой порции тела начинает новый интервал. | С укороченным интервалом тесты проверяют передачу, которая длится дольше одного интервала, и остановку при зависании до заголовков и во время чтения тела. |
| `--format png` проверяет каждый статический PNG по сигнатуре, CRC блоков, `IEND` и декодированию. В этом режиме требуются `200` и тело без HTTP-сжатия. При ошибке CLI сообщает номер запроса и опускает итоговые метрики. | Тесты проверяют корректный PNG без `Content-Length`, повреждение на девятом ответе при прежней длине, отсутствие `IEND`, неверное содержимое при корректных CRC, HTML, `206` и HTTP-сжатие. |
| Публичный репозиторий содержит скрипт, тесты и README с требованиями, командами запуска и единицами измерения. | Открыть README на GitHub и выполнить указанные команды в локальной копии. |
