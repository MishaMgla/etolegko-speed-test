# Критерии приёмки

| Критерий | Как проверить |
| --- | --- |
| CLI принимает один абсолютный URL ресурса по HTTP или HTTPS. Успешный запуск завершается с кодом `0`. | Запустить команду из README с адресом тестового сервера. |
| CLI выполняет ровно 10 запросов GET к указанному URL. Каждый следующий запрос начинается после полного чтения тела предыдущего ответа. | Тестовый сервер считает запросы, отслеживает пересечения и отправляет последнюю часть каждого тела с задержкой. |
| CLI суммирует фактически прочитанные байты тел всех 10 ответов. HTTP-заголовки и служебные данные передачи в объём не входят. | Сервер отдаёт двоичные тела разного размера без `Content-Length`. Тест сверяет результат с точным объёмом `61440` байт. |
| Среднее время в миллисекундах равно сумме длительностей 10 запросов, делённой на 10. Длительность включает ожидание заголовков и чтение тела. | Тест проверяет, что среднее учитывает задержки заголовков и последней части тела, а суммарный замер укладывается во время работы CLI. |
| Скорость в MiB/s равна общему объёму в байтах, делённому на `1 048 576` и суммарное время запросов в секундах. | Тест пересчитывает скорость из напечатанного объёма и среднего времени с учётом округления. Для 10 пустых успешных ответов объём и скорость равны нулю. |
| Неправильные аргументы, ответ вне диапазона `2xx`, обрыв соединения или тайм-аут завершают запуск с кодом `1` и сообщением в stderr. При ошибке итоговые метрики отсутствуют. | Тесты проверяют аргументы, ответы `101`, `302` и `404` и обрыв тела. Тайм-аут первого запроса можно проверить на сервере, который отправляет часть тела и держит соединение открытым дольше 60 секунд. |
| Публичный репозиторий содержит скрипт, тесты и README с требованиями, командами запуска и единицами измерения. | Открыть README на GitHub и выполнить указанные команды в локальной копии. |
