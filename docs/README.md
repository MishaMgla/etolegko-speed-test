## Как устроена документация

Документация организована как дерево. Корневые [README.md](../README.md) и [AGENTS.md](../AGENTS.md) служат точками входа для людей и агентов. Оба файла ведут к этому оглавлению.

Подробные материалы хранятся в `docs/` по темам. Когда у темы появляется несколько страниц, собери их в подпапку с собственным `README.md` и добавь ссылку на него в оглавление родительского раздела. Используй относительные ссылки и обновляй их при переносе или удалении страниц.
