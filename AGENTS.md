# Инструкции для агентов

- Начинай с [оглавления документации](docs/README.md) и открывай разделы, которые нужны для задачи.
- Подробную документацию размещай в `docs/` по темам. При добавлении, переносе или удалении страницы обновляй ссылки в оглавлении её раздела.
- Правила структуры описаны в разделе [Как устроена документация](docs/README.md#как-устроена-документация).
